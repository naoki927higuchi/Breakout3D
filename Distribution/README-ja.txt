NEON BREAK / 3D
Windows 64ビット用 配布パッケージ

■ 起動
ZIPをフォルダーごと展開し、NeonBreak.exeを起動してください。
Unity Editorのインストールは不要です。
NeonBreak_Data、UnityPlayer.dll、MonoBleedingEdgeなどの同梱ファイルは
移動・削除せず、NeonBreak.exeと一緒に保管してください。

■ 操作
マウス / 左右矢印 / A・D：パドルを移動
クリック / Space：ボールを発射
R：再スタート
M：効果音のオン・オフ
Esc：終了

■ ルール
54個のブロックをすべて壊すとクリアです。
赤いブロックは2回当てると壊れます。
壊すたびにボールが少しずつ加速します。
累計5個破壊するごとに、1球ならマルチボールが予約されます。
次にパドルで打ち返すと2球になり、速度も少し上がります。
すべてのボールを落とすとゲームオーバーです。
コンボはパドルに戻るまでの連続破壊数として記録されます。

■ バージョン
同梱のbuild-info.jsonにバージョンとビルド日時を記載しています。

■ 使用技術
Unityで制作。画面・効果音はゲーム内で生成しています。
UnityおよびMono等のランタイムを同梱しています。
